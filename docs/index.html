MCP Server · Mijia / MIoT

米家 MCP Server (miot-mcp)

基于 mijiaAPI 5.x 与小米官方 miot-spec.org 物模型源的产品化米家 MCP 服务。面向“家庭、房间、设备名、场景名”提供稳定、快速的智能家居查询与控制能力。

GitHub 仓库 中文文档 English Docs

面向 AI 客户端

优先暴露清晰稳定的产品级工具，无需客户端预知底层 did / siid / piid 协议字段。

真实家庭场景

支持按家庭与房间浏览、共享设备、多键开关分路子设备定位及自然语言意图控制。

官方物模型对齐

对接 miot-spec.org，自动处理多服务属性去重、中英文枚举映射与数值步长对齐。

高速批量读写

单次请求批量读取设备状态，支持 passToken 静默续期与后台非阻塞扫码登录。

快速开始

pip install -r requirements.txt
python mcp_server/mcp_server.py

MCP 客户端配置

{
  "mcpServers": {
    "mijia": {
      "command": "/path/to/venv/bin/python",
      "args": ["/path/to/miot-mcp/mcp_server/mcp_server.py"],
      "env": {
        "MIJIA_ENABLE_QR": "true",
        "MIJIA_QR_OPEN_MODE": "browser",
        "MIJIA_LOG_LEVEL": "INFO"
      }
    }
  }
}
