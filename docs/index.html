        STEP-BY-STEP GUIDE
        
从零到控制全屋设备，只需 4 步

        

          专为 AI 客户端交互体验打磨：非阻塞后台扫码、passToken 静默续期、每次返回结构化 next_steps 引导。
        

      


      

        

          

            

              STEP 01
              ~30 秒
            

            
安装并挂载 MCP

            
复制上方“一句话指令”交给 AI 自动配置，或使用 pip / Poetry 安装后写入客户端 mcpServers。

          

          
pip install miot-mcp

        


        

          

            

              STEP 02
              首次扫码
            

            
浏览器非阻塞扫码登录

            
对 AI 说“登录米家”，服务会在后台生成并打开 ~/.miot-mcp/qr.html，米家 App 扫码后自动保存凭证并支持静默续期。

          

          
tool: prepare_login() → qr.html

        


        

          

            

              STEP 03
              自动拓扑
            

            
发现家庭、房间与分路开关

            
调用 get_home_overview 获取全屋设备，自动识别共享设备与多键墙壁开关拆分的分路子设备（.s2/.s3）。

          

          
tool: get_home_overview()

        


        

          

            

              STEP 04
              日常使用
            

            
自然语言或结构化控制

            
直接说“把客厅吸顶灯调暗一点”或“执行回家模式”，双层引擎自动对齐物模型步长、枚举与范围。

          

          
tool: control_by_intent()

        

      

    


    
    

      

        ONE-CLICK CLIENT SETUP
        
主流 AI 客户端极速配置

        

          切换你正在使用的客户端，一键复制配置即可接入。支持 macOS、Linux 与 Windows。
        

      


      

        

          
          
          
          
        


        

          

            

              发给 AI 助手的自然语言安装指令
              
            

            

          


          

            
💡 环境变量与最佳实践

            
    
              
  • MIJIA_ENABLE_QR="true"：开启二维码扫码登录支持（默认开启）。
    • 
              
  • MIJIA_QR_OPEN_MODE="browser"：优先使用系统浏览器打开美观的本地扫码页 ~/.miot-mcp/qr.html。
    • 
              
  • MIJIA_LOG_LEVEL="INFO"：支持 DEBUG / INFO / WARNING / ERROR。
    • 
              
  • 凭证保存在 ~/.miot-mcp/auth_data.json，只要 passToken 有效即自动静默续期。

        WHY MIOT-MCP 2.1
        
底层硬核打磨，解决传统米家接入痛点

      


      

        

          
🧬

          
官方 miot-spec.org 强类型对齐

          
自动处理多服务同名属性去重（如 on-2、mode-2），支持中英文枚举值互转（制冷/睡眠/日光/月光）与数值步长自动对齐。

        

        

          
🔀

          
多键开关分路与共享设备支持

          
自动将二键/三键墙壁开关拆分为独立可控的分路子设备（.s2 / .s3），并完整纳入家庭共享设备。

        

        

          
🚀

          
单次请求高速批量读写

          
重构底层状态拉取管线，全屋概览与房间状态查询通过单次批量云端请求完成，大幅降低大模型工具等待延迟。
