ARCHITECTURE & HIGHLIGHTS

        
为什么选择产品化的米家 MCP？

        

          告别繁琐的协议字典查找与阻塞式扫码弹窗，让 Claude、Cursor、Windsurf 等 AI 客户端即刻拥有可靠的智能家居控制力。
        

      


      

        

          
🏠

          
面向真实家庭拓扑

          
先看家庭与房间，再定位设备。原生支持共享设备以及多键墙壁开关拆分的分路子设备（.s2 / .s3）。

        

        

          
🧭

          
自然语言意图 + 强类型双引擎

          
既支持一句话如“把卧室台灯亮度调到 30%”的意图控制，也支持按标准 capability schema 结构化调用。

        

        

          
📐

          
官方物模型自动对齐

          
对接 miot-spec.org，自动处理多服务属性去重（on-2/mode-2）、中英文枚举映射与数值步长对齐。

        

        

          
⚡

          
高速批量读写与静默续期

          
单次云端请求批量读取多设备状态；基于 passToken 自动静默续期，后台非阻塞生成浏览器扫码页。

        

        

          
🔌

          
双层全量设备覆盖

          
高频设备采用标准能力直达（开关、亮度、色温、空调温控、窗帘、风速），长尾设备平滑回退至物模型属性/动作调用。

        

        

          
📦

          
结构化 MCP 资源暴露

          
提供 mijia://homes、devices、scenes、capabilities、service 等 6 大资源 URI，方便 AI 上下文即时挂载。

        

      

    


    
    

      

        
BEST PRACTICE WORKFLOW

        
AI 客户端推荐调用路径

        

          专为大模型工具链设计的四步闭环，每次调用均返回清晰的 next_steps 指引。
        

      


      

        

          STEP 01 · AUTH
          
连接与非阻塞扫码

          
调用 get_service_status 或 prepare_login，自动打开本地 ~/.miot-mcp/qr.html 扫码并持久化凭证。

        

        

          STEP 02 · DISCOVER
          
全屋家庭与房间总览

          
通过 get_home_overview 一次性建立“家庭 → 房间 → 设备与在线状态”的空间拓扑认知。

        

        

          STEP 03 · INSPECT
          
读取状态与能力 Schema

          
调用 get_device_status 与 get_device_capabilities 获取可调范围、步长与枚举值。

        

        

          STEP 04 · EXECUTE
          
意图控制与场景触发

          
使用 control_by_intent、control_device 或 execute_scene 精准完成控制并校验返回结果。

QUICK START

        
3 分钟快速接入

        

          要求 Python 3.10+。推荐使用虚拟环境中的 Python 解释器直接挂载到 Claude Desktop、Cursor 或其他 MCP 客户端。
        

      


      

        

          

            1. 安装与本地握手测试
            
          

          
# 使用 Poetry 安装
poetry install

# 或使用 pip 安装依赖
pip install -r requirements.txt

# 启动 MCP Server
poetry run python mcp_server/mcp_server.py

# 运行握手自检
poetry run python mcp_server/mcp_test.py

        


        

          

            2. mcpServers 配置 (Claude / Cursor / Windsurf)
            
          

          
{
  "mcpServers": {
    "mijia": {
      "command": "/path/to/venv/bin/python",
      "args": [
        "/path/to/miot-mcp/mcp_server/mcp_server.py"
      ],
      "env": {
        "MIJIA_ENABLE_QR": "true",
        "MIJIA_QR_OPEN_MODE": "browser",
        "MIJIA_LOG_LEVEL": "INFO"
      }
    }
  }
}
